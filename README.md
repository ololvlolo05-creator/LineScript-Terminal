**LineScript Terminal** — высокопроизводительный универсальный терминал для Windows, объединяющий возможности нативных консолей **PowerShell** и **CMD** с поддержкой декларативного языка оркестрации **LineScript v1.1**.

> 📖 **Официальная спецификация и документация языка:**  
> Полное руководство, реестр стандартных команд и EBNF-грамматика доступны в репозитории [LineScript-Docs](../LineScript-Docs/README.md).

---

## 🌟 Ключевые возможности

* ⚡ **Потоковый вывод в реальном времени (Streaming stdout / stderr):**  
  Команды вроде `ping`, `dotnet build`, `git clone`, `npm install` или `python` выводят текст на экран построчно без задержек.
* ⌨️ **Интерактивный ввод в `stdin`:**  
  Поддержка интерактивных CLI-утилит: когда процесс ждёт ответа (`[Y/N]`, пароль, имя), ввод с клавиатуры мгновенно передаётся в стандартный поток запущенного процесса.
* 🛑 **Надёжная отмена (`Ctrl+C`):**  
  Мгновенное завершение дерева процессов (включая дочерние утилиты) с немедленным возвратом консольного промпта.
* 🔄 **Прозрачная работа с PowerShell и CMD:**  
  Выполняйте любые привычные команды ОС, конвейеры `|`, перенаправления. Переключение оболочки по умолчанию: `mode ps` или `mode cmd` (или через меню *Оболочка*).
* 📜 **Поддержка спецификации LineScript v1.1:**  
  * Выполнение блоков `-cmd-`, `-ps-`, `-git-`, `-file-`, `-file-up-`, `-del-file-`.
  * Бинарные данные: `-file-bin-` (чтение и запись файлов через Base64).
  * Контекстное применение diff-патчей (`-patch-`) с автоматическим бэкапом в `.ls_backup` и возможностью мгновенного отката (`-undo-`).
  * Сортировка составных сценариев по префиксам шагов `[N]`.
  * Экранирование терминатора `\--/-\-`.
* 🖱️ **Удобство использования (UI/UX):**  
  * **Drag & Drop:** перетаскивание файлов или папок из Проводника Windows прямо в окно вставляет их путь в строку ввода.
  * **Контекстное меню мыши:** Копировать, Вставить, Очистить экран, Прервать процесс.
  * **Поиск по истории (Ctrl+R)** и автодополнение по **Tab**.
  * Очистка консоли: `Ctrl+L`, `cls` или `clear`.

## 🚀 Сборка и запуск

### Требования
* Windows 10 / 11 (x64)
* .NET SDK 10.0 (для компиляции из исходников)

### Сборка автономного исполняемого файла (.exe):
```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
Готовый компактный файл создаётся в папке:  
`bin/Release/net10.0-windows/win-x64/publish/LineScriptTerminal.exe`
